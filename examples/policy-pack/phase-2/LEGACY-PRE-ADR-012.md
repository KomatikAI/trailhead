# Legacy Phase 2 Snapshot

Everything below this directory predates ADR-012. The bundled workflows publish or
require native workflow-job contexts, use Trailhead v3, and do not listen for recorded
override label changes. They are retained as rollout history only.

For current enforcement, use:

- `../github-ruleset.main-only.json` or `../github-ruleset.progressive.json`;
- the v4 workflow generated by `trailhead init` or shown in
  `../../../docs/getting-started.md`;
- the custom `Trailhead — Release Ready` check with GitHub Actions as expected source.
